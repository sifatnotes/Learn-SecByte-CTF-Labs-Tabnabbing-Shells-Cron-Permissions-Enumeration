## Learning Path

A practical progression through this collection:

1. **Start with enumeration**  
   Begin with Sleepy Enum Lab to develop a structured Linux discovery methodology.

2. **Understand shells and TTYs**  
   Continue with Sleepless TTY and Sleepy Shells to build familiarity with shell-access concepts.

3. **Study tabnabbing scenarios**  
   Work through Tabnabbing Stabilizer and Sleepy Tabnabbing Shells, then explore Tab Trap Shellcraft.

4. **Investigate Python and scripts**  
   Study Sleeping Tabs Python Hijack and Sleepy Script Sleuth.

5. **Learn scheduled-task security**  
   Move to Sleeping Cron, Napping Tasks, and Cronnap: Sleeping Root.

6. **Finish with permissions and escalation**  
   Complete PermSnap: Owners, Bits & Escalation to connect ownership, permission bits, and privilege-escalation concepts.

## How to Use the Labs

- Use every lab only in an authorized CTF or cybersecurity training environment.
- Begin with enumeration before testing possible escalation paths.
- Document shell behavior, TTY state, file permissions, ownership, scripts, and scheduled tasks.
- When studying cron, understand both the execution mechanism and its security implications.
- For Python and script challenges, inspect execution context and permissions carefully.
- Treat shell and root-access scenarios as controlled training objectives.
- After each lab, identify appropriate defensive controls and hardening measures.
- Never apply these techniques to systems without explicit authorization.
